About Smart Contact Manager

Easily manage and access all your personal and professional contacts — secure, fast, and user-friendly. Get started today and simplify your contact management experience.

Get Started Read More

Overview

The Smart Contact Manager is a secure and feature-rich web application built with Spring Boot, Spring Security, and PostgreSQL. It helps users manage their personal and professional contacts efficiently while ensuring privacy and providing a smooth user experience.

Key Features

  • Role-based access control (User / Admin)
  • Profile photo upload stored in user-specific folders
  • Add, update, and delete multiple contacts with ease
  • Strong protections against URL tampering / unauthorized access
  • Admin dashboard with full visibility and analytics

Why This Project?

This project demonstrates expertise in full-stack development, authentication, secure CRUD operations, and scalable architecture. It is useful both as a professional portfolio piece and as a reliable internal tool for managing contacts.
